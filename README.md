# Лабораторная работа №3

## 1. Задание

Модифицировать программу из лабораторной работы №1 для параллельной работы по технологии MPI.  
Провести серию экспериментов с разным количеством процессов (1, 2, 4), разными размерами матриц (200, 400, 800, 1200, 1600, 2000).

## 2. Программа

- `mpi_matrix_mult.cpp` — параллельное умножение квадратных матриц с использованием MPI
- `verify.py` — автоматическая верификация результата
- `run_experiments.py` — запуск серии экспериментов
- `result.txt` — файл с результатом перемножения матриц
- `matrix_a.txt`, `matrix_b.txt` — входные данные

## 6. Выводы

В ходе лабораторной работы программа умножения квадратных матриц была модифицирована для параллельной работы с использованием MPI. Проведенные эксперименты показали, что при увеличении числа процессов время выполнения уменьшается.

Наиболее заметное ускорение наблюдается на больших размерах матриц, где вычислительная нагрузка выше, а влияние накладных расходов на обмен данными между процессами меньше.

Эксперименты с 8 процессами также проводились, однако результаты оказались нестабильными и в ряде случаев уступали запуску на 4 процессах. Это связано с ограничениями аппаратных ресурсов используемой виртуальной машины и хостовой системы, а также с ростом накладных расходов на взаимодействие между MPI-процессами. Поэтому для основного анализа в отчете приведены результаты для 1, 2 и 4 процессов как наиболее корректные и воспроизводимые.

Во всех экспериментах корректность вычислений была подтверждена автоматической верификацией.
